# 🐟 ঘেরের স্মার্ট খাতা Pro - Android APK Build Project

এই প্রজেক্টটি **"ঘেরের স্মার্ট খাতা Pro" (Aquaculture & Fish Farming ERP)** এর একটি পূর্ণাঙ্গ অ্যান্ড্রয়েড অ্যাপ প্রজেক্ট। এটি **GitHub Actions** এর মাধ্যমে ক্লাউডে স্বয়ংক্রিয়ভাবে কম্পাইল হয়ে ডাউনলোডযোগ্য `.apk` তৈরি করে দেয়। আপনার কম্পিউটারে কোনো ভারী সফটওয়্যার (যেমন Android Studio) ইনস্টল করতে হবে না।

---

## 🚀 কীভাবে GitHub থেকে APK ডাউনলোড করবেন?

### ধাপ ১: গিটহাবে কোড আপলোড / পুশ করুন
এই রিপোজিটরিটি গিটহাবে পুশ করার সাথে সাথেই ক্লাউড বিল্ড স্বয়ংক্রিয়ভাবে শুরু হয়ে যাবে।

### ধাপ ২: অ্যাকশন ট্যাবে যান (Actions Tab)
1. আপনার GitHub রিপোজিটরিতে ঢুকে উপরের মেনু থেকে **"Actions"** ট্যাবে ক্লিক করুন।
2. বাম পাশের মেনুতে **"Build Gher Smart Khata APK"** দেখতে পাবেন।
3. আপনি চাইলে **"Run workflow"** বাটনে ক্লিক করেও যেকোনো সময় নতুন APK বিল্ড করতে পারেন।

### ধাপ ৩: APK ডাউনলোড করুন
- বিল্ড সম্পন্ন হতে সাধারণত **২-৩ মিনিট** সময় লাগে এবং পাশে সবুজ টিক চিহ্ন (✔️) আসবে।
- বিল্ডটির ওপর ক্লিক করলে নিচের দিকে **"Artifacts"** সেকশনে `Gher-Smart-Khata-Pro-APK` ফাইলটি দেখতে পাবেন।
- ক্লিক করলেই আপনার ফোনে বা পিসিতে সরাসরি ইনস্টলযোগ্য `.apk` ডাউনলোড হয়ে যাবে!
- এছাড়াও **Releases** ট্যাবে গেলে সরাসরি এক ক্লিকে ডাউনলোড করার লিংক পেয়ে যাবেন।

---

## 📱 মোবাইলে ইনস্টল ও ব্যবহারের নিয়ম

1. ডাউনলোড করা `Gher-Smart-Khata-Pro.apk` ফাইলে ট্যাপ করুন।
2. ফোনে যদি "Unknown sources" বা "Install unknown apps" মেসেজ আসে, তবে **"Allow / Settings -> Allow from this source"** সিলেক্ট করুন।
3. **Install** এ চাপুন।
4. ইনস্টল হয়ে গেলে অ্যাপটি ওপেন করুন।

---

## ✨ অ্যান্ড্রয়েড সংস্করণের বিশেষ সুবিধাসমূহ:

1. **সম্পূর্ণ অফলাইন কার্যক্ষমতা**: ঘেরে কোনো ইন্টারনেট বা ওয়াইফাই না থাকলেও অ্যাপটি নিরবচ্ছিন্নভাবে চলবে।
2. **ক্যামেরা ও গ্যালারি সাপোর্ট**: কাস্টমারের ছবি তোলার জন্য সরাসরি ফোনের ক্যামেরা ওপেন হবে।
3. **ছবি স্বয়ংক্রিয় কম্প্রেশন**: স্মার্টফোনের বড় সাইজের ছবি স্বয়ংক্রিয়ভাবে ছোট (Compressed ~25KB) হয়ে সেভ হবে, ফলে ফোনের মেমোরি ফুল হবে না।
4. **প্রিন্ট ও মেমো পিডিএফ**: অ্যান্ড্রয়েডের নিজস্ব প্রিন্টারের সাথে যুক্ত, ফলে মেমো সরাসরি ব্লুটুথ থার্মাল প্রিন্টারে প্রিন্ট বা PDF হিসেবে সেভ করা যাবে।
5. **ব্যাকআপ ও রিস্টোর**: এক ক্লিকে সম্পূর্ণ হিসাবের JSON ফাইল ডাউনলোড এবং নতুন ফোনে রিস্টোর করার সুবিধা।
